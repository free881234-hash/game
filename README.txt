다크월드 웹 버전 (아이폰 / 아이패드 / PC 브라우저)
================================================

이 폴더 전체를 웹에 올리면 Safari에서 바로 실행됩니다. 앱 설치·서명이 필요 없습니다.
(파일을 더블클릭해서 여는 방식은 안 됩니다. 반드시 https 주소로 열어야 합니다.)

0. PC 크롬에서 바로 하기
  - "웹버전 실행 (PC 크롬).bat"을 더블클릭하면 검은 창이 뜨고 크롬이 자동으로 열립니다.
  - 게임하는 동안 검은 창은 닫지 마세요. (윈도우 보안 경고가 나오면 "실행"을 눌러 주세요)
  - 저장은 이 주소(localhost)용으로 따로 보관됩니다.

1. 올리기 (둘 중 하나)
  [가장 쉬움] Netlify Drop
    - PC 브라우저에서 https://app.netlify.com/drop 접속
    - 이 폴더(darkworld-web)를 통째로 끌어다 놓기 → https://xxxx.netlify.app 주소가 생김
    - 무료 회원가입 후 "Claim"을 눌러 두어야 주소가 계속 유지됩니다.
  [GitHub Pages]
    - 새 저장소를 만들고 이 폴더 안의 파일을 모두 올린 뒤
      Settings → Pages → Branch: main / root 로 지정 → https://아이디.github.io/저장소/

2. 아이폰에서 실행
  - Safari로 주소 열기 → 아래 공유 버튼 → "홈 화면에 추가"
  - 홈 화면 아이콘으로 실행하면 주소창 없이 전체 화면으로 실행되고, 한 번 받은 뒤에는 오프라인에서도 실행됩니다.
  - 가로로 돌려서 플레이하세요.

3. 저장
  - 진행 저장은 게임 안에서 저장하면 브라우저에 자동 보관됩니다.
  - 오른쪽 위 ⚙ → "저장 내보내기"로 .dwsave 파일을 만들 수 있습니다(폰 APK·PC판과 같은 형식).
  - 폰/PC의 .dwsave 파일을 아이폰으로 옮긴 뒤(에어드롭, 파일 앱, 카카오톡 등) ⚙ → "저장 가져오기"로 불러옵니다.
  - Safari는 "홈 화면에 추가"하지 않은 사이트의 저장 데이터를 오래 안 쓰면 지울 수 있습니다.
    홈 화면 아이콘으로 쓰고, 가끔 내보내기로 백업해 두세요.

4. 조작
  - 화면의 방향패드·공격·스킬·DASH·스킬 세트 전환 버튼을 누르면 됩니다(동시 터치 가능).
  - 공격/스킬 버튼을 누르고 있으면 PC판처럼 연속 입력됩니다.
  - 블루투스 게임패드, 키보드(PC 기본 배치)도 사용할 수 있습니다.
  - 업스케일(xBR): 게임 메뉴 → 시스템 → 환경설정 → 화면연출 → 업스케일, 또는 ⚙ 메뉴.
  - 치트 설정/상점: 게임 안 메뉴(폰판과 같은 위치) 또는 ⚙ 메뉴.
